## ผลสรุป / Headline numbers
- 28 โพสต์ (Instagram 11, X 13, YouTube 4) ข้อมูล ณ 28 ก.ย. 2026 เวลา 16:43–17:00 น.
- Engagement รวม **114,533** (Likes + Comments + Repost/RT) · ยอดดู ≈ **811.8K**
- EMV **$8,118** (วิธี A: Views ÷ 1,000 × CPM $10) หรือ **$11,453** (วิธี B: Engagement × CPE $0.10) เลือกใช้วิธีเดียว
- MIV ประมาณ **$8.1K–$12.2K** (ยอดที่เก็บได้จริง) และอาจถึง $32.8K ถ้าเติมช่องทางและเสียงที่ยังไม่ได้เก็บ

## ข้อสมมติและข้อจำกัด / Assumptions
- CPM $10, CPE $0.10 และตัวคูณ MIV 1.0–1.5 เป็นค่าสมมติ ควรแทนด้วย rate card จริง
- MIV จริงเป็นโมเดลเฉพาะของ Launchmetrics ตัวเลขนี้เป็นเพียงค่าประมาณ
- ทุกโพสต์เป็นของสื่อและแฟนเพจ ไม่รวมโพสต์ของแอนตัน RIIZE หรือ YSL เอง และไม่รวม TikTok, Weibo, Xiaohongshu
- สถานการณ์ B–D ใช้สัดส่วนจากเบนช์มาร์ก Launchmetrics PFW FW25 (ภาพรวมงาน ไม่ใช่เฉพาะ Saint Laurent SS27) จึงเป็นการประมาณ
- ตัวเลข K เป็นค่าปัดเศษ, likes ของ emoz.mag และยอดดูของบางโพสต์ยังขาด, ค่าจะเพิ่มขึ้นตามเวลา
